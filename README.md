# AI-IDS-ES

**AI-assisted intrusion detection / network security project for packet-capture analysis.**

## System requirements

- Linux, macOS, or Windows WSL2
- Python 3.10+
- 2 GB RAM minimum; 4 GB recommended
- About 1 GB storage
- `libpcap-dev`
- Administrator/root privileges for live capture

## Project focus

**Network Security • Intrusion Detection • Packet Capture • AI/ML**

Use the repository's existing implementation files as the source of truth for installation and execution details.
